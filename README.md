## ✨ 功能一览

### 🌙 暗黑模式一键切换

顶栏右上角月亮/太阳按钮，一键切换全站暗黑模式。

- 覆盖 60+ 个 Discourse CSS 变量，帖子页、编辑器、弹窗、侧边栏全部适配
- **夜间对比度专项修复**：个人主页元信息、帖子操作区、代码块语法高亮、私信用户名等在暗色下会"糊"的文字均按 WCAG AA 校准（只调明度/重绑变量，不影响品牌色与状态色）
- **图片亮度自动调节**：白底截图、照片自动降亮一档，头像、表情、Logo 不受影响；悬停还原原色
- 偏好自动保存，下次打开自动跟随

### 📊 列表页数据增强

| 增强项 | 效果 |
| --- | --- |
| ❤️ 点赞数 | 浏览量旁边显示该帖累计点赞 |
| 🔥 热门标识 | 热度 ≥ 70 的帖子自动标记 |
| ✅ 已解决徽章 | 已采纳答案的帖子标题旁显示 `✓ 已解决` |

### 🌡️ 帖子温度计

每行一条迷你温度条：`热度 = 点赞(40%) + 回复(35%) + 浏览(25%) × 时间衰减`（7 天半衰期）。悬停看明细。

### 📈 热度排序

列表页可按热度升/降序：表头 `🌡热度` 列 + "新建话题"左侧按钮双入口；状态持久化；点击原生排序自动清除。

### 🎲 随机漫游

顶栏骰子按钮，随机打开一个帖子（基于官方 sitemap，约 9 万话题；数据源不可用时降级到最新列表）。

### ⬆️ 一键回到顶部

右下角圆形按钮，下滑超过约一屏浮现，点击平滑回顶。

### 😄 情绪标记（实验）

列表页标题前显示情绪表情：**😄 喜 ｜ 😠 怒 ｜ 😢 哀 ｜ 😅 反讽 ｜ 🆘 求助**，中性不显示。

- 判定走**结构+句式规则**（请求式/转述/双重否定/转折/分类与已解决信号），不是裸词表；拿不准一律不标
- 每个表情可悬停看判定理由；对读屏器有 `aria-label` 中文说明
- **已知限制**：仅基于标题（"标题级粗判"），正文不参与；规则基于小样本验证，误判会存在，仅供扫读参考

### 📊 今日情绪面板（实验）

左下角「📊 今日情绪」折叠条，点击展开：今天 00:00 至今发布帖子的情绪分布与各类代表帖子链接。

- 数据来自列表接口（`order=created` 翻页），按 topic id 去重；30 分钟缓存，不重复请求
- 超过 150 帖时显示"仅统计最新 150 条"截断提示
- 请求失败时面板保留并显示"点击重试"，不会悄悄消失

**总开关**：顶栏 😄 按钮（骰子、暗黑按钮旁边）点击即开/关，跨会话记住。关闭后标记、面板、面板请求**全部停止**（0 请求）。旧版 Console 开关 `tfe-emotion-off` 会自动迁移。

## 🛠️ 技术实现

- **纯本地运行**：`@grant none`，不申请任何油猴特权
- **三路数据源兜底**：拦截站内 `fetch` → 解析首屏预载 → 兜底请求列表 `.json`
- **零侵入**：钩子均包裹容错；情绪模块复用同一 MutationObserver（120ms 防抖），不另开观察者
- **面板韧性**：列表页判定独立于热度排序的 URL 白名单（修正 `/top`⊂`/topic` 误匹配）；路由变化自动重挂/移除；失败可重试
- **夜间修复为纯 CSS**：零运行时开销

## ⚠️ 已知限制

- 情绪判定为**标题级粗判**（不读正文），规则基于小样本验证，误判存在；泛化能力未验证
- 今日面板超过 150 帖会截断并明确提示；统计为当日 00:00 本地时间起
- 私信界面文字修复因测试账号无私信会话，未经渲染验证
- 登录态管理/设置类页面的夜间对比度未全量验证
- 多标签页同时打开时，开关状态以后写者为准（无跨标签同步）

## ❓ FAQ

**Q：情绪标记怎么关？**
A：顶栏 😄 按钮点一下即可（变灰=关），跨会话记住；面板和请求会一起停。

**Q：切换暗黑模式后个别图片很刺眼？**
A：正文图片会自动降亮（`brightness(0.85)`），悬停还原原色；头像、表情、Logo 不受影响。

**Q：列表页数据偶尔显示不出来？**
A：数据来自列表接口，网络波动时可能延迟 1-2 秒；刷新即可。

**Q：论坛官方改版后脚本会失效吗？**
A：脚本只依赖 Discourse 标准结构（2026.x），兼容性较好。若失效请提 [Bug 反馈](../../issues/new?template=bug_report.yml)。
